# republic_of_ireland_plate

Republic of Ireland's licence plates for plate_core: the standard white plate and the green-strip electric plate, with the EU band and Irish county names, and more.

## Quick start

### Install (TypeScript)

Copy `typescript/src/countries/republic_of_ireland/` into `plate_core/typescript/src/countries/`.

Then run the tests from `plate_core/typescript/`: `npm test`.

### Use

```ts
import country from './countries/republic_of_ireland';

const spec = country.specs.get('ie.standard');
console.log(country.package);
```

## Specs

The specs are the same in every language (they come from shared data).

- `ie.standard`
- `ie.electric`

## Themes

- `RepublicOfIrelandThemes.standard`

## Change it

- Specs: `country.specs`, by id.
- Themes: `country.themes`.
- Validators: `country.validators` (`RepublicOfIrelandValidator`).
