# republic_of_ireland_plate

Republic of Ireland's licence plates for plate_core: the standard white plate and the green-strip electric plate, with the EU band and Irish county names, and more.

## Quick start

### Install (Python)

Copy `python/plates/countries/republic_of_ireland/` into `plate_core/python/plates/countries/`.

Then run the tests from `plate_core/python/`: `pytest`.

### Use

```python
from plates.countries.republic_of_ireland.data import SPECS, THEMES

spec = SPECS["ie.standard"]
theme = THEMES["RepublicOfIrelandThemes.standard"]
print(spec.id)
```

## Specs

The specs are the same in every language (they come from shared data).

- `ie.standard`
- `ie.electric`

## Themes

- `RepublicOfIrelandThemes.standard`

## Change it

- Pick a spec: use another key of `SPECS`.
- Pick a theme: use another key of `THEMES`.
- Validators: `VALIDATORS` maps the names `RepublicOfIrelandValidator` to classes.
